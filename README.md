# Plane Icebox görev formu

Kullanıcı yolculuklarına odaklanan Türkçe görev hazırlama arayüzü. React, Mantine, Radix, Apache ECharts ve Phosphor ile tek HTML dosyası olarak derlenir.

Canlı sayfa: https://karacaismail.github.io/plane-icebox-form/

Ana eylem **Icebox’a gönder**. Bu sürüm UI/frontend önizlemesidir; Plane API entegrasyonu sonraki aşamada eklenecektir. Görev bilgileri yalnızca tarayıcıda saklanır. Dosyalar taslağa kaydedilmez. JSON dışa aktarma, geri alma ve benzer görev oluşturma kullanılabilir.

0.4.1: Dolu giriş kartları, adım rozetleri ve büyük ikonlar geri getirildi; semi-flat görsel dil form geneline uygulandı. Yazılar en az 1 rem, köşeler en fazla 12 px. Açık/koyu tema, 320 px–8K düzeni ve gönderim önizleme akışı doğrulandı.
