# Plane Icebox görev formu

Kullanıcı yolculuklarına odaklanan Türkçe görev hazırlama arayüzü. React, Mantine, Radix, Apache ECharts ve Phosphor ile tek HTML dosyası olarak derlenir.

Canlı sayfa: https://karacaismail.github.io/plane-icebox-form/

Görev bilgileri yalnızca tarayıcıda saklanır. Dosyalar taslağa kaydedilmez. Form JSON üretir; Plane'e otomatik gönderim yapmaz.
